# automotive-ai-knowledge-hub

Automotive AI Knowledge Hub - A complete automotive industry local RAG system powered by Grok AI with interactive dashboards and citation support.

## Setup
1. Clone the repo: `git clone https://github.com/shabihassan/automotive-ai-knowledge-hub.git`
2. Install requirements: `pip install -r requirements.txt`
3. Set your environment variable: `export XAI_API_KEY='your-grok-key'`
4. Run the app: `python app.py`
